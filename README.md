Projetos para firmar a lógica: variáveis, condicionais, laços e funções. 

Nesse sistema é possivel criar um cadastro de uma pessoa, com nome, idade e email.

O sistema impede a criaçao de dois cadastros com mesmo email.

Possibilida a busca de cadastro por email.

Listagem de cadastros.

Exclusão por email, com confirmação.

Possibilita também a edição de cada um dos campos da entidade.

Armazenamento dos cadastros em coleção List<Pessoa>

Menu de navegação via terminal.

O sistema possui a entidade modelada separadamente
